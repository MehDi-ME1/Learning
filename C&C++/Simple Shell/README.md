## Simple Shell
The Simple Shell implenentation has several key concepts that will create the concrete of system programming.
There will be a second version of this project soon. and the developments will be announced at the time.
Details about implementation and development of each version is placed inside their own README.md file.

### How to run
Running this program is only availabel on Linux or a Unix-like os. 
- Compile with gcc compiler (C99 version support suggested).
- Run the executable program.
